# 🤝 Comunidad — Mentoría y Syncs (Fase 3 del plan)

> Activación: cuando el proyecto tenga **3+ colaboradores activos**.
> Este documento define el marco para cumplir las promesas de mentoría,
> canal privado y syncs de CONTRIBUTOR_LEVELS.md.

## 👥 Mentoría

### Reglas de emparejamiento
| Mentor (nivel) | Mentee (nivel) | Áreas posibles |
|---|---|---|
| 🦝 Raccoon+ | 👾 Pixel | Docs, primer PR, entorno de desarrollo |
| 🦊 Fox+ | 🐝 Flyer / 🐧 Penguin | Código, tests, firmware, app móvil, IA |
| 🐺 Wolfy | 🐧 Penguin+ | Liderazgo de área, arquitectura |

### Compromisos del mentor
- Revisar los PRs del mentee con comentarios constructivos (sin promesa de 48h).
- Orientar en issues "good first issue" (#27–#31).
- Recomendar el ascenso de nivel cuando se cumplan los criterios.

### Compromisos del mentee
- Leer CONTRIBUTING.md antes del primer PR.
- Preguntar en el issue correspondiente antes de abrir uno nuevo.

## 🔄 Syncs mensuales
- **Cuándo:** primer sábado de cada mes (hora por acordar con los colaboradores activos).
- **Formato:** llamada grabada de 45 min.
- **Agenda tipo:**
  1. Estado de issues y PRs (5 min)
  2. Demo de lo nuevo (10 min)
  3. Bloqueos y ayuda necesaria (15 min)
  4. Ascensos de nivel del mes (5 min)
  5. Roadmap: siguientes pasos (10 min)
- **Acta:** publicada como issue etiquetado `sync` tras cada reunión.
- **Invitación:** todos los niveles 🐧 Penguin+ (como promete CONTRIBUTOR_LEVELS.md).
