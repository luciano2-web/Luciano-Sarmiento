# 🤝 Cómo Contribuir — Luciano Sarmiento

¡Gracias por tu interés en colaborar! Aquí te explico cómo hacerlo.

## Antes de empezar
1. **Lee** los [issues abiertos](https://github.com/luciano2-web/Luciano-Sarmiento/issues)
2. **Comenta** en el issue si quieres trabajar en algo (evita trabajos duplicados)
3. **Pregunta** si algo no está claro — no soy experto en todo

## Guía rápida

### 1. Fork
Haz click en el botón "Fork" arriba.

### 2. Clona tu fork
```bash
git clone https://github.com/tu-usuario/Luciano-Sarmiento.git
cd Luciano-Sarmiento
```

### 3. Crea tu rama
```bash
git checkout -b feature/lo-que-haces
```

### 4. Trabaja
- Escribe código limpio
- Incluye tests si aplica
- Actualiza docs si modificas algo

### 5. Commitea
```bash
git add .
git commit -m "Descripcion clara de tu cambio"
```

### 6. Push y PR
```bash
git push origin feature/lo-que-haces
```
Luego abre un PR explicando qué hiciste.

## Etiquetas clave
- `good first issue` — Ideal para empezar
- `help wanted` — Necesito colaboración urgente
- `bug` — Cosas rotas
- `enhancement` — Mejoras propuestas
